完整本地 preflight 包含 7 个单测、Python/JSON 语法、章节合并一致性和本地链接检查。Compose 已用占位参数只读展开，核对三服务及空间3/1挂载，没有通过该检查创建容器。

Gitleaks 与两枚已知客户端 token、模型 Key 的无回显匹配均无命中。交互图的 validate、deliver、check、browser-check 均通过；未将自动浏览器检查称为人工观感验收。

来源链接采用命令行和页面工具交叉核对：GitHub、Docker、SQLite、Mihomo 文档可访问；OpenAI Help 对命令行抓取返回 403，但页面工具可以读取原文及域名表。该差异是访问方式限制，不写成所有 curl 均200。

指南所述 NAS/Codex/DSH 真实对话、重启和备份结果来自原部署验收；本次发布没有在另一台全新 NAS 完整重装，也没有重新进行付费校准、生产恢复或长时压力测试。

监控相关 7 个测试与原有 7 个测试均通过。现网已验证四容器状态、两端 MCP、worker 心跳、只读 SQLite/WAL 聚合、通知提交和用户确认 Bark 收件；单独停止面板的外部探针演练与整机断电是不同验收范围。公开模板不含真实 IP、私有路径或 SendKey。交互部署图使用 Archify 3.2.0 重新生成，四项自动化检查通过，人工页面验收针对实际运行面板。
